Class (keys 1–9)

Boxes in this frame

Keys

  • drag on empty area: new box
  • drag inside a box: move; near a corner: resize
  • 1–9 class (also changes the selected box)
  • i toggle ignore (dashed) on selected box
  • Del/Backspace delete selected box
  • Space mark done, next frame
  • ←/→ previous / next frame
  • h hold: hide boxes (see what is under them)

Guidelines

  • Box every visible object of the classes, also when nothing moves.
  • truck = whole vehicle incl. trailer and load.
  • container = only containers not on a vehicle, one box per stack block.
  • ignore = < ~12 px high, mostly hidden, cut by the edge, or behind the OSD.
  • An empty frame is a valid label: mark it done.
